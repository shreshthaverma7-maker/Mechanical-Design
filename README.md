# Mechanical-Design Engineer
A universal joint (U-joint) is a mechanical connector that allows rotary motion to be transmitted between two shafts that are not aligned in a straight line. It consists of a cross-shaped center piece with bearings that enable flexible movement, allowing the shafts to rotate at different angles.
